# Git hooks — `.githooks/`

Repo-tracked git hooks for QUAD-Client. Git does not run hooks from a
tracked directory automatically; each clone must point git at this
directory once:

```bash
git config core.hooksPath .githooks
```

## Hooks

| Hook         | Purpose |
|--------------|---------|
| `commit-msg` | Rejects AI/LLM authorship attribution in commit messages. |

### `commit-msg`

Blocks commit messages that credit an AI assistant instead of describing
the change:

- `Co-Authored-By:` trailers naming a model or vendor (Claude, Opus,
  Sonnet, Haiku, GPT, ChatGPT, Copilot, Gemini, Codex, Anthropic, OpenAI,
  Llama, Mistral, …) or a `noreply@anthropic.com`-style address.
- `🤖 Generated with ...` / "Generated by \<AI tool\>" footers.

It targets **attribution lines only** — ordinary prose that mentions a
product as part of the change description is allowed, e.g.
_"list codex alongside Claude Code as supported MCP clients"_.

If a commit is rejected, remove the offending trailer/footer and commit
again. To bypass in a genuine emergency: `git commit --no-verify`.
